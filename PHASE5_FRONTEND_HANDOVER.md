# Phase 5 Frontend Handover

The `mintly-react` folder is the UniWallet React frontend. The project remains React/Vite; no Flutter work is included.

Phase 5 frontend changes are documented in `mintly-react/docs/PHASE5_FRONTEND_QA.md`.

Before merging the eventual GitHub frontend branch, compare its changed `mintly-react/src` files against this build. Preserve the Phase 4 API contracts unless the new branch intentionally changes them and the backend is updated at the same time.
